# SketchAquifer

Enhances data-driven geospatial decision-making through real-time data processing and integration with the Aquifer System Platform.

SketchAquifer is aimed at developers who need a straightforward, dependable solution.

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchAquifer.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure SketchAquifer, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
